1. **Open this folder** on your laptop or phone
2. **Read QUICK_START.txt** - it's only 5 minutes
3. **Follow the steps** - laptop first, then phone
4. **Test everything** before the service starts
5. **Keep this folder accessible** during the service

## 📋 What to Bring

- [ ] Laptop (charged) with FL Studio project saved
- [ ] Phone (charged) with MIDIFlow installed
- [ ] This backup folder (on USB or in cloud)
- [ ] Church Wi-Fi password OR phone hotspot
- [ ] Power cables

## 🔧 If Something Goes Wrong

1. **Check CHURCH_GIG_CHECKLIST.txt** - it has troubleshooting for every issue
2. **Try restarting the app** - most issues are fixed by this
3. **Use FL Studio's built-in controls** - you can always play without the remote
4. **Don't panic** - the music is what matters, not the remote
